markdown# 🚀 Spring Boot アーキテクチャ＆設計思想 まとめメモ

Java 21 と Spring Boot 環境における、実務レベルのWebアプリケーション設計の全貌。

---

## 1. コントローラーの基本と挙動の違い

ブラウザからの窓口となるコントローラーは、付けるアノテーションによって `return`（戻り値）の意味が真逆になる。

| アノテーション | 戻り値（`return`）の扱い | 主な用途 |
| :--- | :--- | :--- |
| **`@RestController`** | 文字列をそのまま**レスポンスボディ**として返す | APIの作成、HTML文字列を直接ブラウザに出したいとき |
| **`@Controller`** | 戻り値を**「画面（テンプレート）のファイル名」**として扱う | ThymeleafなどのHTMLファイルに遷移させたいとき |

### 💡 補足：`@RequestMapping` の `value` とは？
* Flaskでいう `@app.route('/...')` の「ルート（ルーティング）」と完全に同じ意味。
* Web業界では **「エンドポイント」** や **「リクエストパス」** と呼ぶ。
* 実務では、**エンドポイント名と関数（メソッド）名は言葉の意味を一致させる**のが鉄則（コードが探しやすくなるため）。

---

## 2. Javaのイニット（コンストラクタ）と特殊な動き

クラス名と完全に同じ名前のメソッドは、Pythonでいう `__init__` と同じ初期化メソッド。中の `super();` は `super().__init__()` と同義。

### 💡 ここでしかできない2つの特殊な動き
1. **`final`（固定化）変数の初期化**：一度入れたら二度と上書きできない安全な鍵（`final`）をかけられる。
2. **コンストラクタ注入（DI）**：引数に他の部品（Serviceなど）を書いておくと、Spring Bootが起動時に自動でガッチャンコ（注入）してくれる。

## 3. 実務の4層構造（アーキテクチャ）と繋ぎ方

システムを4つのリモコン（クラス）に細かく分けることで、「どこが壊れているか」を一発で特定できるようにする設計。

```text
 [ブラウザ]
     │ (URLでアクセス)
     ▼
┌───────────────────────────┐
│ ① コントローラー層        │ ➔ 窓口。リクエストを受け付け、結果を返す
└────────────┬──────────────┘
             │ 【 繋ぎ方：コンストラクタ注入 (DI) 】
             ▼
┌───────────────────────────┐
│ ② サービス層              │ ➔ アプリの交通整理。どのリモコンをどう動かすかのシナリオ
└────────────┬──────────────┘
             │ 【 繋ぎ方：コンストラクタ注入 (DI) 】
             ▼
┌───────────────────────────┐
│ ③ 実務層（ビジネスロジック）│ ➔ コアなビジネスルール、計算、重複チェックなど
└────────────┬──────────────┘
             │ 【 繋ぎ方：コンストラクタ注入 (DI) 】
             ▼
┌───────────────────────────┐
│ ④ DAO / リポジトリ層      │ ➔ データベース（SQL）の操作。
│  (名前だけのインターフェース)│   開発者は「メソッド名（SQLの動き）」を名付けるだけ！
└────────────┬──────────────┘
             │ 【 繋ぎ方：Spring Bootが裏で「継承（extends）・実装」を自動生成 】
             ▼
 [ データベース (MySQL等) ]
```

### 🔑 繋ぎ方の鉄則
* **DI（部品としての保持・利用）**：
  上の層が下の層を「お抱えの専門部品」として呼び出すときは、すべてコンストラクタによる **DI** で繋ぐ（疎結合にするため）。
* **継承（`extends`）**：
  ④のDAO層が、Spring Bootが最初から用意してくれている強力な型（`JpaRepository`など）の機能をまるごと引き継ぐとき**だけ**に使う。

## 4. 最小構成のコード例（ブラウザに太字で名前を出す）

```java
package com.example.demo;

import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class HelloWorldController {

    // デフォルトコンストラクタ（通常は省略可能だが、Pythonの__init__と同じ役割）
    public HelloWorldController() {
        super();
    }

    // producesでContent-Type（HTML、文字コードUTF-8）を明示してWバイト文字（日本語）の文字化けを防ぐ
    @RequestMapping(value = "/show-name", produces = "text/html;charset=UTF-8")
    public String showName() {
        // 文字列がそのままレスポンスボディに流れる。strongタグでBold体（太字）にする
        return "<h1><strong>山田 太郎</strong></h1>";
    }
}
```
